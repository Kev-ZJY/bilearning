# 数据与隐私

## 源码仓库包含什么

公开仓库只包含程序代码、空白配置示例、构建配置和公开文档。它不包含开发者原 Git 历史、测试、聊天记录、数据库、个人目录、视频、转写、知识文档、截图、日志、模型权重、真实 `.env` 或访问凭据。

## 运行时的数据流

| 数据 | 位置或接收方 |
|---|---|
| 视频、音频、逐秒帧、转写、阶段工件 | 本机存储根目录或所选项目目录 |
| 项目索引、消息、任务记录、知识版本 | 本机 SQLite |
| 正式 HTML / Markdown 与快照 | 项目目录中的知识文件及 `.video-workbench/` |
| 转写、知识和生成/审核需要的证据 | 你配置的模型接口供应商 |
| Bilibili 元信息和媒体请求 | Bilibili 及相关 CDN |
| 审核所需网页查询和正文请求 | 相应的公网服务与站点 |
| Whisper 权重 | 首次使用可从模型分发服务下载并缓存在本机 |

仓库不预置开发者模型账户，也没有独立的项目遥测服务。第三方请求仍会遵循其自身记录与数据政策；“本地应用”不表示所有处理都离线完成。

## 密钥

浏览器开发模式可通过环境变量或界面配置，保存的值可能位于本机数据库。macOS 外壳通过 Keychain 管理密钥；本次会话设置与持久配置分别处理。显示为掩码不等于原始数据已经加密。

不要提交真实 `.env`、Cookie、Keychain 导出、数据库或运行日志。需要分享问题时，先删除密钥、个人路径、视频内容和聊天记录。`.gitignore` 只能减少后续误提交，不能删除已经写入 Git 历史的信息。

## 本机访问边界

默认开发服务和 Compose 端口只绑定本机。项目以单用户运行设计，不提供完整的公网多用户认证、账户隔离或云端队列。将其作为互联网服务部署前，需要自行补齐这些能力。
